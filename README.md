# qa-1348-isolated

A small, dependency-free implementation of the QA Retest header.

## Run locally

Serve the repository with any static web server, for example:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>. The header is implemented in `index.html` and `styles.css`; `script.js` provides the accessible mobile navigation toggle. No build step or package installation is required.
